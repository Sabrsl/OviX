# CORRECTION: Composants système - Double namespace résolu

## PROBLÈME
Les routes système et autres routes backend ne pouvaient pas accéder aux managers:
- Kill switch manager not available
- Scheduler state manager not available
- Published tracker not available
- Analyzed tracker not available
- Database not available

## CAUSE
Double namespace Python: `api.main` vs `backend.api.main`

- **Démarrage**: `backend/api/main.py` chargé → Module enregistré comme `api.main` → Managers initialisés ✅
- **Appel route**: Routes importent `import backend.api.main as main_module` → Module chargé comme `backend.api.main` → Variables globales = None ❌

## SOLUTION APPLIQUÉE (Option 1)
Correction de tous les imports pour utiliser le même namespace que l'initialisation:

### Pattern de correction
**Avant:**
```python
import backend.api.main as main_module
return main_module.get_kill_switch()
```

**Après:**
```python
from api.main import get_kill_switch
return get_kill_switch()
```
